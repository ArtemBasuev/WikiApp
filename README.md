# WikiApp

Мультиплатформенное приложение (Kotlin Multiplatform + Compose Multiplatform) для чтения статей Википедии: список статей с поиском, экран статьи, избранное, светлая и тёмная тема, русская и английская локализация.

В текущей версии (B1) данные моковые: статьи берутся из локального списка. Структура проекта подготовлена к тому, чтобы заменить источник данных на реальный API без изменений в экранах.

## Предметная область

Основная сущность — **статья Википедии** (`WikiPage`):

| Поле | Описание |
|---|---|
| `pageid` | Уникальный идентификатор статьи |
| `title` | Заголовок |
| `extract` | Краткое содержание (вводный абзац) |
| `fullurl` | Ссылка на оригинал |
| `length` | Размер статьи в байтах |
| `touched` | Дата и время последнего изменения (ISO 8601) |
| `categories` | Категории статьи (`Category`) |
| `links` | Ссылки на другие статьи (`PageLink`) |

Сценарии пользователя:

1. **Список.** Пользователь видит список статей, может искать по заголовку и тексту. Статьи подгружаются порциями по мере прокрутки.
2. **Статья.** По нажатию открывается экран с заголовком, метаданными, категориями, текстом и ссылками на связанные статьи. Нажатие на ссылку открывает связанную статью.
3. **Избранное.** Статью можно добавить в избранное и просмотреть список избранного отдельным экраном.
4. **Тема.** Тема переключается с экрана списка (по умолчанию берётся системная).

## Запуск

Требуется JDK, совместимый с версией Gradle проекта (рекомендуется JDK 17 или новее). Gradle Wrapper скачает остальное автоматически.

Десктопное приложение:

```bash
./gradlew :desktopApp:run
```

На Linux и macOS, если `gradlew` не запускается из-за прав доступа:

```bash
chmod +x gradlew
```

Веб-версия:

```bash
./gradlew :webApp:wasmJsBrowserDevelopmentRun
```

Android-версия:

```bash
./gradlew :androidApp:assembleDebug
```

Проверка локализации:

```bash
python tools/check-strings.py
```
